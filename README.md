## DMIT 优化线路是什么：先把概念搞清楚

DMIT 的线路分三档，这是理解后续所有套餐的基础：

**Premium（Pro 系列）** 是旗舰档，专门为中国大陆用户做了三网路由优化。电信走 CN2 GIA（AS4809）高端专线，联通走 AS9929 精品线路，移动走 CMI/CMIN2。这套配置的特点是晚高峰稳——不是"平时好晚高峰变鬼"那种，而是延迟曲线基本不抖的那种稳。

**Eyeball（EB 系列）** 是平衡档。洛杉矶 EB 的回程走三网 CMIN2，去程电信联通走 CN2，移动走香港 CMI。价格比 Pro 低一档，但线路质量比 T1 强不少，联通移动用户用 EB 的体感有时候比 Pro 还好。

**Tier 1（T1 系列）** 是经济档，国际线路，没有专门的中国大陆优化。价格便宜，流量给得足，适合不需要大陆直连、主要做开发测试或服务海外用户的场景。

有一点很多人没注意：香港和东京的 T1，对大陆访问几乎没有优化，电信联通可能绕路到日本甚至更远，延迟反而比洛杉矶的 Pro 套餐还高。被"香港离得近"的直觉坑过的人不在少数。

## 三大机房的 DMIT 优化线路实测数据

### 洛杉矶（LAX）

用的人最多，套餐也最全。Pro 系列晚高峰平均延迟在 140–180ms 之间，实测丢包率基本压在 0.1% 以下，跑 V2Ray 节点能跑到 60Mbps+，4K 视频流畅不卡顿。

说实话，跨太平洋 140ms 的延迟没什么惊喜，但惊喜在晚高峰——同价位很多商家到晚 8 点就开始抽风，DMIT 的 CN2 GIA 管道够宽，这段时间基本感觉不到明显波动。

EB 系列走 CMIN2 回程，联通移动用户的感受普遍好评，电信用户的话 Pro 系列更合适。

还有一个比较特殊的系列：洛杉矶 sPro（Premium Secure），在 CN2 GIA 线路基础上叠加了 CFMT 5Tbps+ DDoS 高防直连。去程走高防，回程走 CN2 GIA。跑游戏服务器、被打过的站点适合考虑。

### 香港（HKG）

物理位置最近。Pro 系列延迟通常在 10–50ms，电信走 CN2 GIA，联通走 AS9929，移动走 CMI，三网都是精品线路配置。

代价是贵。入门 TINY 套餐 $39.90/月，是洛杉矶同类套餐的四倍。不是随便买的价位，但如果业务对延迟极度敏感——比如实时交互类应用、对国内用户访问速度要求苛刻——香港 Pro 是 DMIT 产品线里最合适的选择。

EB 系列通过 CMI 线路提供中等质量连接，从 $29.90/月起，对预算有限但仍想用香港节点的用户来说是个合理折中。

### 东京（TYO）

延迟介于香港和洛杉矶之间，大约 50–80ms，线路配置和香港 Pro 类似：电信 CN2 GIA、联通 AS9929、移动 CMI。适合需要日本本地 IP 的场景，比如日区流媒体、面向日本用户的服务、亚太节点分散部署。

顺便提一嘴：东京 Eyeball 系列目前已经下架了，如果你之前看过有文章提到 TYO.EB，现在官网已经没有了，不用再找。

## 按需求选套餐：直接给结论

不同需求对应的 DMIT 优化线路选法，列出来直接用：

1. **电信用户，需要大陆直连** → 洛杉矶 Premium（LAX.Pro）系列，CN2 GIA 双向优化，去回程都走高端线路
2. **联通/移动用户，追求性价比** → 洛杉矶 Eyeball（LAX.EB）系列，CMIN2 回程对联通移动更友好，价格和 Pro 系列相同但流量更多
3. **对延迟极度敏感，业务核心在国内** → 香港 Premium（HKG.Pro），延迟 10–50ms，但价格是洛杉矶的四倍，算清楚再买
4. **需要日本 IP，面向亚太用户** → 东京 Premium（TYO.Pro），延迟 50–80ms，线路配置和香港同级
5. **开发测试、海外业务为主，不需要大陆优化** → 洛杉矶 Tier 1（LAX.T1），流量大，价格低，AMD EPYC 硬件性能够用
6. **预算最低，只想入门试试** → 洛杉矶 T1 WEE 年付，$36.9/年，国际线路，能跑任务

有一条原则值得记住：**不要因为"香港/东京离得近"就去买这两个机房的 T1 系列**。没有大陆优化的前提下，地理位置近不代表访问快，电信联通很可能绕更远。

## 几个新手常问的问题

**Q：DMIT 的 IP 被封了怎么办？**

Premium 和 Eyeball 系列每 15 天可以免费换一次 IP（IP 真的被封的情况），其他情况收 $5 一次。目前已支持用户自助在后台换 IP，不用提工单等客服，方便很多。

**Q：流量用完了会不会直接断网？**

T1 和部分 Eyeball 套餐流量耗尽后会自动降速继续使用，不会直接切断。对个人用户来说这个设计很友好，不用每天盯着流量计。

**Q：不满意可以退款吗？**

3 天内、使用流量不超过 30GB 可以申请全额退款。30 天内还可以按比例退还剩余金额（退至账户余额免手续费，原路返回可能有手续费）。对新用户来说试错成本不高，不确定适不适合可以先买最小套餐跑一下。

**Q：支持支付宝/微信吗？**

支持。支付宝、微信、PayPal 都可以，国内用户付款没有障碍。

**Q：新注册账号可以马上下单吗？**

DMIT 对新注册账号有一段等待期才能下单，建议提前几天注册好账号，避免到时候着急买不了。
